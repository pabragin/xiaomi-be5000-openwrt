steer plugins for Xiaomi BE5000

Protocol plugins (.s2p) of splify2/steer 2.1.4 built for arm_cortex-a7 with software floating point: the AN7563 CPU has no FPU and no NEON, and the upstream release has no build for it. The steer-core package from the BE5000 feed reads this repository instead of the upstream one.

apk update
apk add steer-core

This is an unofficial build. The index and the archives are signed with the keys of this feed, not with the splify2 keys. Plugins: net1, vless, hysteria2, proxy, xsteer, obfs, warpbox, awg. Index: index.json.
