Kernel modules for OpenWrt on Xiaomi BE5000

apk feed with every kernel module (kmod-*) of the images from pabragin/xiaomi-be5000-openwrt. downloads.openwrt.org has no airoha/an7563 target, so modules for these images come only from here.

One directory per kernel build: kmods/<kernel version>-<vermagic hash>/. Images from the release that published the directory point their target feed at it on first boot, so this works out of the box:

apk update
apk add kmod-wireguard

Modules load only into the kernel they were built with. After installing a newer image, use its own directory (the image does that by itself).
